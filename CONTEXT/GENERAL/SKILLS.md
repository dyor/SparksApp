# Agent Skills Reference

This document is the central registry for all specialized agent capabilities (skills). Each skill is documented in its own file, linked below. Before starting a task, review the relevant skill(s) to ensure you are following the correct procedures and conventions.

## Core Skills

*   **[Spark Development](./skills/spark_development.md)**
    *   Guides the end-to-end process of building a new Spark.

*   **[Settings Design](./skills/settings_design.md)**
    *   Ensures consistent application of UI patterns for Spark settings screens.

*   **[Shared Components](./skills/shared_components.md)**
    *   Instructions for using and creating reusable UI components.

*   **[Shared Services](./skills/shared_services.md)**
    *   Guidelines for using shared business logic and backend services.

## Technical Skills

*   **[Notifications & Feedback](./skills/notifications.md)**

## Workflow & Environment
